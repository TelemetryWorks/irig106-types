# irig106-types

**Note:** This crate is currently a placeholder.

This crate is being developed to provide zero-cost abstractions and foundational types for IRIG 106 telemetry. It isolates the core domain model, providing a strictly defined, memory-safe vocabulary for building high-performance aerospace data systems without the overhead of I/O or parsing logic.

We have secured this name on `crates.io` while finalizing the initial version.

Please check the [active GitHub repository](https://github.com/TelemetryWorks/irig106-types) to see our current progress.
